# Python To-Do App



Полноценное приложение для управления задачами с REST API и веб интерфейсом.



# Технологии

Backend: Python, FastAPI, SQLite

Frontend: HTML, CSS, JavaSckript

Инструменты: uv, Docker, Git

Деплой: Alwaysdata (CI/CD через GitHub Actions)





Вы можете посмотреть работу приложения здесь: https://to-do.alwaysdata.net



# Docker

Проект также упакован в Docker. Запуск: `docker run -p 8000:8000 privateface/my_todo:latest`
